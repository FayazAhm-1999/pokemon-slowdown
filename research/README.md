# Research

Background material kept for context. None of this ships in the binary.

- `codex-build-prompt.md` — the original build brief this project was built
  against: scope, architecture constraints and acceptance criteria.
- `mockup-1.png`, `mockup-2.png` — visual references for the intended feel.

Filenames here are deliberately ASCII. Go refuses to build a module archive
containing non-ASCII paths, which breaks `go install`, so the original em-dash
filename had to go.
